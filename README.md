# 谱间音频分离

免费、无需注册的离线六轨分离工具：人声、吉他、钢琴、贝斯、鼓、其他伴奏。

此仓库公开分享安装包和用户文档。构建源码保持私有，私人录音与实验数据不随程序分发。

Windows 10/11 x64 和 Apple Silicon macOS 13+ 将在各自构建、完成离线验收后同时发布。当前正在准备测试版，尚无可公开下载的安装包。正式下载请以本仓库 Releases 中实际发布的文件和 SHA-256 为准。

完整安装包包含运行环境、固定 Demucs htdemucs_6s 模型及离线解码器。安装后无需 Python、Node 或联网下载模型。支持 MP3/WAV/M4A/FLAC，单文件 100 MB，单次片段最长 10 分钟。

第三方组件、模型来源和许可随完整安装包提供。
